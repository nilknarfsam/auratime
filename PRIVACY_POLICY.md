# Política de Privacidade - AuraTime

O aplicativo AuraTime respeita a privacidade dos seus usuários e não coleta, armazena ou compartilha dados pessoais com terceiros.

## Coleta de dados

O AuraTime não coleta dados pessoais identificáveis. Todas as informações inseridas pelo usuário, como registros de ponto e configurações, são armazenadas localmente no dispositivo.

## Uso de dados

Os dados inseridos são utilizados exclusivamente para funcionamento do aplicativo, como controle de jornada e geração de relatórios.

## Compartilhamento de dados

O aplicativo não compartilha dados com terceiros.

## Backup de dados

O usuário pode exportar manualmente seus dados por meio da funcionalidade de backup. Esses arquivos são de responsabilidade do usuário.

## Segurança

Como os dados são armazenados localmente, o controle e a segurança das informações dependem do próprio usuário.

## Alterações nesta política

Esta política pode ser atualizada futuramente para refletir melhorias no aplicativo.
