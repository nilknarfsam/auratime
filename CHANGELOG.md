# Changelog

Todas as mudancas relevantes do projeto AuraTime sao registradas neste arquivo.

## [0.1.0] - 2026-04-29

### Added
- Dashboard premium com status do dia, progresso da jornada e resumo semanal.
- Tela de historico com filtros por periodo, resumo consolidado e cards aprimorados.
- Tela de configuracoes com personalizacao de nome e jornada.
- Persistencia de configuracoes via SharedPreferences.
- Integracao de relatorio PDF com dados configurados.

### Changed
- Identidade visual inicial de versao alpha (icone e splash).
- Versionamento do app para `0.1.0+1`.
- Estrutura de navegacao com modulo de configuracoes.

### Notes
- Build alpha inicial para validacao funcional e de UX.
